# 시간표 (Timetable)

로그인 없이 바로 쓰는 간단한 주간 시간표 앱입니다. 수업, 일과, 약속을 요일과 시간에 맞춰 배치하고, 지금 진행 중인 일정을 한눈에 확인하세요.

## 주요 기능

- **쉬운 편집**: 빈 시간을 눌러 일정을 추가하고, 드래그로 이동하거나 위·아래 핸들로 길이를 조절합니다. 10분 단위로 정밀하게 맞출 수 있습니다.
- **일정 정보**: 제목, 색상, 장소를 담을 수 있습니다.
- **현재 일정 표시**: 지금 진행 중인 일정에 테두리가 표시되고, 앱을 열면 현재 시각으로 자동 이동합니다.
- **홈 화면 위젯**: 진행 중인 일정의 시간, 제목, 장소를 홈 화면에서 바로 확인합니다.
- **알림**: 일정 10분 전과 시작 시각에 매주 알림을 받을 수 있습니다.
- **저장본 관리**: 시간표를 여러 개 저장해 두고 필요할 때 불러옵니다.
- **내보내기와 공유**: PDF, PNG 이미지로 저장하거나 공유 버튼으로 에어드롭을 통해 시간표를 전달 할 수 있습니다.
- **보기 설정**: 주말 표시, 24시간제, 하루 시작·종료 시각, 한국어·영어를 설정합니다.

## 개인정보

계정이 필요 없고, 모든 데이터는 기기 안에만 저장됩니다. 서버로 전송하거나 수집하지 않습니다.
