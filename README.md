# 시간표 (Timetable)

로그인 없이 바로 쓰는 간단한 주간 시간표 앱입니다. 수업, 일과, 약속을 요일과 시간에 맞춰 배치하고, 지금 진행 중인 일정을 한눈에 확인하세요.

## 주요 기능

- **편집 모드**: 화면 위쪽의 "편집" 스위치를 켜면 일정을 추가하고 고칠 수 있습니다. 끄면 시간표를 보기만 하므로, 스크롤하다가 일정을 잘못 건드려 바뀌는 일이 없습니다.
- **쉬운 편집**: 편집 모드에서 빈 시간을 길게 눌러 일정을 추가합니다. 일정을 한 번 눌러 선택한 뒤 드래그로 요일과 시간을 옮기거나, 위·아래 핸들로 길이를 조절합니다. 10분 단위로 맞출 수 있고, 일정은 30분보다 짧아지지 않습니다.
- **바로 반영되는 일정 편집**: 일정을 길게 누르면 편집 창이 열리고, 제목과 색상을 바꾸는 즉시 시간표에 반영됩니다. 다른 요일로 복사하거나 삭제할 수도 있습니다.
- **현재 일정 표시**: 지금 진행 중인 일정에 테두리가 표시되고, 앱을 열면 현재 시각으로 자동 이동합니다.
- **시간표 패널**: 화면 오른쪽 끝에서 왼쪽으로 스와이프하면 저장된 시간표와 프로필을 관리하는 패널이 열립니다.
- **시간표 목록**: 시간표를 여러 개 만들어 두고, 목록에서 누르면 바로 불러옵니다. 새로 추가한 시간표는 항상 목록 맨 위에 오고, 목록에는 마지막으로 저장한 시각이 표시됩니다.
- **저장**: 고친 내용은 목록의 "저장" 버튼을 눌러야 시간표에 기록되므로, 마음에 들지 않는 편집은 저장하지 않고 되돌릴 수 있습니다. 바뀐 내용이 없으면 "저장" 버튼은 비활성됩니다. 저장하지 않은 채 다른 시간표로 옮기면 먼저 저장할지 물어봅니다.
- **복제**: 목록의 "..." 메뉴에서 "복제"를 누르면 시간표를 복사해 목록에 추가합니다. 비슷한 시간표를 새로 만들 때 편리합니다.
- **새 시간표**: "새 시간표"를 누르면 빈 시간표가 목록에 추가되고, "26년도 겨울 시간표"처럼 연도와 계절로 이름이 붙습니다.
- **프로필**: 프로필마다 시간표와 설정을 따로 관리할 수 있습니다.
- **홈 화면 위젯**: 진행 중인 일정의 시간과 제목을 홈 화면에서 바로 확인합니다.
- **알림**: 일정 10분 전과 시작 시각에 매주 알림을 받을 수 있습니다. 시간표가 바뀌면 알림도 자동으로 갱신됩니다.
- **내보내기와 공유**: PDF, PNG 이미지로 저장하거나 시간표 파일로 공유할 수 있습니다. 에어드롭이나 파일 앱으로 받은 시간표 파일은 앱에서 열어 바로 가져옵니다.
- **보기 설정**: 하루 시작·종료 시각과 한국어·영어를 설정합니다.

## 개인정보

- 계정이 필요 없고, 모든 데이터는 기기 안에만 저장됩니다. 서버로 전송하거나 수집하지 않습니다. 
- 앱을 삭제하면 앱에 저장된 모든 데이터도 함께 삭제됩니다. 단, 직접 내보내 저장하거나 공유한 파일은 삭제되지 않습니다.
